# Ghestban Update Channel

این مخزن فقط کانال عمومی انتشار و بروزرسانی قسط‌بان است و نباید حاوی بکاپ یا داده مالی شخصی باشد.

## معماری ساده انتشار

- **Windows:** یک فایل `Ghestban.html` / `index.html` مستقل؛ بدون نصب، Python، Node، BAT یا PowerShell. در نبود اینترنت کامل آفلاین کار می‌کند. هنگام اتصال، نسخه جدید را بررسی و با تأیید کاربر فایل جدید را دانلود می‌کند.
- **Mobile / Browser:** نسخه PWA از GitHub Pages با Service Worker و قابلیت کار آفلاین پس از نصب.
- **Backup/Sync:** جدا از بروزرسانی و فقط در مخزن خصوصی `GhestbanData`.

## فایل‌های اصلی

- `index.html` — نسخه برنامه
- `manifest.json` — مشخصات PWA
- `sw.js` — کش آفلاین و بروزرسانی کنترل‌شده PWA
- `version.json` — نسخه جاری
- `updates.json` — تاریخچه و تغییرات نسخه‌ها
- `icons/` — آیکون‌های PWA

داده‌های مالی و GitHub Token بکاپ هرگز نباید در این مخزن قرار گیرند.
